# BackPipe (Backend Pipeline)

Этот проект является персональной утилитой для пакетного изменения размеров фотографии по шаблону.   

Ему необходимо указывать файл или директорию для обработки, директорию для результата, конфиг файл и опционально количество используемых потоков
(по умолчанию 6).   

Утилита создаёт директорию с названием шаблона по пути для результата, переиминовывает каждое фото чтобы добавить название шаблона в конце.   

*Пожалуйста учтите, что эта утилита работает только на Linux, поскольку требует inotify*   
*Если вы хотите использовать её на MacOS или Windows, перейдите на ветку DevOps за версией на Docker*

---

#### Как установить:

Скачайте проект:
```
git clone https://github.com/reaktivnii/BackPipe
```
Используйте CMake для компиляции:
```
mkdir build
cd build
cmake ..
cmake --build .
```
В директории bin/ в корне появится исполнительный файл

---

#### Как использовать:

Для использования вызывайте утилиту подобным образом:
```
./bin/backpipe -c вашконфиг.txt -i вход -o выход/
```
Дополнительно вы можете указать флаг -t чтобы указать, сколько потоков использовать.

Также эта утилита может работать в режиме сервиса: используйте флаг -s и укажите ***директорию*** на вход (вместе с прочими основными параметрами)
чтобы запустить сервис.   
Он будет ожидать изменений в указанной директории с помощью inotify (просто переместите/копируйте фото в директорию) и автоматически применять шаблон к новым фото.

---

##### Полное описание флагов:

-c / --config - путь к файлу с шаблоном (пример такого конфига ниже);
-i / --input - путь к файлу или директории к обработке;
-o / --output - путь для результатов работы;
-t / --threads - сколько потоков использовать в работе (рассчитывайте, ориентируясь на физические потоки вашего процессора, если указать больше то прироста к производительности не будет);
-s / --service - запустить BackPipe как сервис.

---

##### Конфиг составляется по простой логике:

[название_конфига]
[нужно ли сохранять соотношение сторон от оригинала]
[ширина результата]
[высота результата, если соотношение выключено]
[какой формат результата, jpg или png]
[если jpg, качество от 0 до 100]

К примеру
```
example:
save_aspect=false
width=2000
height=1335
format=jpg
quality=95
```

Количество шаблонов в рамках одного txt файла не ограничено.
Файл должен быть обычным txt
Текст должен быть на английском языке.

---

*Манипуляция изображений реализована с помощью библиотек nothings/stb (image, resize2, write)*
